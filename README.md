# Tabula

Самостоятельная замена новой вкладки в виде **электронной таблицы** с листами, темами и фоном.
Работает в **Chromium-браузерах** (Chrome, Edge, Brave, Opera, Vivaldi…) и **Firefox** (109+).
Автор: **withersky**.
Без подписок, без телеметрии, всё хранится локально в `chrome.storage.local` / Firefox Storage.
Интерфейс — на русском, переключается на английский в настройках.

## Что внутри

- **Сетка как Excel** — каждая ячейка содержит ровно одну закладку (или пустая). Можно положить закладку в любую рандомную ячейку. Пустые/заполненные не привязаны к сетке «строка = закладка».
- **Листы** внизу как вкладки Excel:
  - Кнопка `＋` добавляет новый лист (можно задать emoji-иконку).
  - Двойной клик по вкладке — переименовать.
  - Правый клик — переименовать / задать emoji-иконку / задать количество колонок / удалить.
  - Вкладки можно перетаскивать мышью для изменения порядка.
  - У каждого листа своё количество колонок (3–12) и emoji-иконка.
- **Взаимодействия с ячейками**:
  - Клик по заполненной — открыть (или в новой вкладке, если включено).
  - Клик по пустой — только выделяет ячейку (без открытия модалки).
  - Правый клик — контекстное меню (открыть / в новой вкладке / изменить / дублировать / удалить).
  - Перетаскивание заполненной на пустую — переместить. На заполненную — поменять местами (с тостом).
- **Поиск/быстрый переход** сверху (опционально — можно скрыть).
- **Плавающая кнопка настроек** (⚙) в правом верхнем углу — открывает страницу настроек.
- **Анимации**: появление модалок, контекстных меню, тостов, переключение темы, добавление листов — плавные, через CSS keyframes.
- **Настройки** (открываются иконкой на новой вкладке):
  - **Оформление**: переключатель темы (тёмная / светлая) в стиле переключателя языков, галочка «Показывать линии сетки».
  - **Сетка**: колонок в новых листах (3–12), размер ячеек (масштаб 20–200%, пересчитывается при ресайзе окна).
  - **Текст**: шрифт (CSS), размер шрифта, цвет текста.
  - **Фон** (пять режимов):
    - Сплошной цвет
    - CSS-градиент
    - URL изображения
    - **Загрузить своё изображение** (сохраняется прямо в `chrome.storage.local`, лимит ~2 МБ)
    - **Bing: изображение дня** — подгружается ежедневно через service worker, кешируется на день
  - **Ячейки**: тонкий серый фон при выделении ячейки, без зебры.
  - **Поведение**: показывать фавиконы, открывать в новой вкладке, номера строк, буквы колонок, показывать вкладки листов, **показывать поисковую строку**, показывать линии сетки, показывать часы, показывать виджет погоды.
  - **Язык интерфейса**: Русский / English.
  - **Виджеты**: часы (тоггл, шрифт, размер) и погода (тоггл, город, координаты, размер виджета, период обновления; клик по виджету открывает Яндекс.Погоду по координатам).
  - **Заголовок вкладки**: собственный текст, который Chrome показывает в заголовке окна/вкладки (по умолчанию — «Новая вкладка»).
  - **Импорт/экспорт** всего датасета в JSON.
- **Хоткеи**: `/` — фокус на быстрый переход, `N` — добавить закладку в первую пустую ячейку активного листа, `Esc` — закрыть модалку/снять фокус.
- **Локализация**: все надписи в `lib/storage.js`, переключение языка применяется «на лету».

## Установка

### Chrome / Chromium / Edge / Brave…

1. Откройте `chrome://extensions` (или `edge://extensions` и т.п.).
2. Включите **Режим разработчика** (сверху справа).
3. **Загрузить распакованное расширение** → выберите папку с расширением.
4. Откройте новую вкладку — должна появиться таблица.
5. Нажмите ⚙ в правом верхнем углу (или иконку расширения в тулбаре) — откроются настройки.

> Если другое расширение уже переопределяет `chrome_url_overrides.newtab`, отключите его —
> браузер использует только одно такое расширение одновременно.

### Firefox (109+)

1. Откройте `about:debugging#/runtime/this-firefox`.
2. Нажмите **Загрузить временное дополнение…** и выберите **`manifest.firefox.json`** из корня проекта.
3. Откройте новую вкладку — появится Tabula.

> В Firefox MV3 service worker поддерживается только с версии **121**. Чтобы расширение работало
> и на **109–120**, в Firefox-сборке используется классический `background.scripts` (event page).
> Для этого применяется отдельный манифест `manifest.firefox.json`.

## Сборка релизов

В проекте лежит `build.sh`, который копирует исходники в `dist/` и подставляет нужный манифест:

```bash
./build.sh chrome    # -> dist/chrome/  (используется manifest.json)
./build.sh firefox   # -> dist/firefox/ (используется manifest.firefox.json)
./build.sh all       # -> оба варианта
```

Полученные папки — это и есть то, что нужно упаковывать/загружать в соответствующий магазин
(Chrome Web Store, AMO).

### Автоматический релиз через GitHub Actions

В репозитории лежит воркфлоу [`.github/workflows/release.yml`](.github/workflows/release.yml:1).
При каждом push в `main`/`master` (или ручном запуске через **Run workflow**) он:

1. Берёт **первую строку** commit message. Если она начинается с `vX.Y.Z` —
   парсит версию и идёт дальше; иначе тихо завершается (обычные коммиты не ломают билд).
2. **Проверяет**, что поле `"version"` в [`manifest.json`](manifest.json:1) и
   [`manifest.firefox.json`](manifest.firefox.json:1) совпадает с `X.Y.Z`. Если нет — workflow
   падает с понятной ошибкой. Это страховка от рассинхрона тега и реальной версии расширения.
3. Прогоняет `./build.sh all` и упаковывает оба варианта в
   `tabula-chrome-vX.Y.Z.zip` и `tabula-firefox-vX.Y.Z.zip`.
4. Создаёт/перемещает git-тег `vX.Y.Z` на текущий коммит.
5. Публикует GitHub Release с прикреплёнными архивами. Release notes — это
   полный текст commit message с заголовком `## vX.Y.Z`.

#### Процедура релиза

1. Поднять версию в **обоих** манифестах (`manifest.json`, `manifest.firefox.json`) на `X.Y.Z`.
2. Сделать commit, **первая строка** сообщения которого выглядит так:

   ```text
   v1.2.3 - короткое описание релиза

   - подробности изменения 1
   - подробности изменения 2
   ```

3. `git push origin main`. Через ~30 секунд в разделе **Releases** появится
   `v1.2.3` с двумя zip-файлами.

#### Требования к репозиторию

В **Settings → Actions → General → Workflow permissions** должен быть включён
**Read and write permissions** (нужно для создания тегов и релиза). Этого достаточно,
дополнительные секреты не нужны — workflow использует встроенный `GITHUB_TOKEN`.

Для публикации в магазинах используйте `./build.sh chrome` и `./build.sh firefox`.

## Кросс-браузерная совместимость

Для Chrome и Firefox используется одна и та же кодовая база. Все обращения к API расширения
проходят через тонкую обёртку [`lib/browser.js`](lib/browser.js:1):

- `ext.runtime.sendMessage` — унифицирует Promise-API Firefox и callback-API Chrome;
- `ext.runtime.openOptionsPage` / `getManifest`;
- `ext.storage.local.get / set / remove`;
- `ext.storage.onChanged`.

В [`background.js`](background.js:1) обёртка подключается через `importScripts("lib/browser.js")`
(работает и в service worker Chrome, и в background scripts Firefox). В [`newtab.html`](newtab.html:1)
и [`options.html`](options.html:1) обёртка подключается обычным `<script>` перед `lib/storage.js`
и основным скриптом страницы.

### Миграция

`Storage.get()` автоматически поднимает старые форматы до текущего:

- **v1** (`tabs` + `groups`) → каждая «группа» становится отдельным листом с 8 колонками.
- **v2** (`sheets[].tabs`) → каждый `tab` превращается в `cells["row,0"]`; порядок сверху-вниз сохраняется.
- **v3** (текущий, `sheets[].cells`) — без миграции.

После миграции данные сохраняются обратно в `chrome.storage.local` под новым ключом, чтобы при следующем запуске не повторять работу.

## Действия с листами (правый клик на вкладке)

- **Переименовать** — ввести новое имя (должно быть уникальным).
- **Иконка** — задать emoji-иконку для вкладки листа (или двойной клик по самой иконке).
- **Удалить лист** — с подтверждением (если это единственный лист, удалить нельзя).

## Действия с ячейками

| Действие                       | Жест / клавиша                                  |
|--------------------------------|-------------------------------------------------|
| Открыть закладку               | Клик по заполненной ячейке                      |
| Открыть в новой вкладке        | ПКМ → «Открыть в новой вкладке» или Ctrl/Cmd+клик |
| Добавить закладку              | ПКМ по пустой ячейке → «Добавить сюда» или `N`  |
| Редактировать                  | ПКМ → «Изменить» или двойной клик               |
| Дублировать                    | ПКМ → «Дублировать»                             |
| Удалить                        | ПКМ → «Удалить»                                 |
| Перетащить                     | Drag из заполненной на пустую → переместить      |
| Поменять местами               | Drag из заполненной на заполненную → swap        |

## Заметки

- **Фавиконы** подгружаются через Google Favicon Service (`https://www.google.com/s2/favicons?domain=...`). Если иконки нет — показывается буквенный бейдж.
- **Загруженные изображения** хранятся прямо в `chrome.storage.local` как data URL. Лимит ~2 МБ; большие файлы отклоняются.
- **Bing daily** — фон подгружается через service worker, который делает запрос напрямую к `bing.com` (нужны `host_permissions` в манифесте). Результат кешируется в `bingCache` до конца дня. При ошибке остаётся прежний фон и показывается тост.
- **Синхронизация** между устройствами не предусмотрена — используйте экспорт/импорт JSON.
- **Manifest V3**, Chrome 108+. Firefox не поддерживается (нужны `browser_specific_settings` и работа с `chrome://favicon`).

## Кастомизация

Частые правки:

- Стартовый список закладок и листов — `defaultData()` в `lib/storage.js`.
- Дефолтная тема — объект `settings` там же.
- CSS-переменные (`--columns`, `--cell-height`, `--font-family`, `--font-size`, `--clock-size`, `--weather-size`, `--topbar-height`, `--sheet-bar-height` …) описаны в `:root` в `newtab.css`. Реальное значение `--cell-height` (в пикселях) пересчитывается в [`applyCellScale()`](newtab.js) на основе `settings.cellHeight` (%) и высоты окна.
- Переводы — добавьте язык в `I18N` в `lib/storage.js` и значение `<option>` в `options.html` (`#languageSelect`).
