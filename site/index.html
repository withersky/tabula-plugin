Возможности

🗂️

Листы как в Excel

Несколько листов-вкладок с emoji-иконками, перетаскиванием для смены порядка и своим числом колонок (3–12).

🧩

Сетка ячеек

Каждая ячейка — одна закладка. Перетаскивайте их, меняйте местами, открывайте в новой вкладке и редактируйте правым кликом.

🎨

Оформление

Цветовая палитра, шрифты, CSS-градиент, своя картинка или Bing-обои дня — всё настраивается в один клик.

🌤️

Часы и погода

Крупные часы и виджет погоды (данные — открытый сервис met.no). Настраиваются шрифт, размер и период обновления.

🔍

Быстрый поиск

Строка быстрого перехода с подсказками и выбором поисковой системы: Google, Яндекс или Bing.

🔒

Приватность

Никакой телеметрии и облаков: все данные живут локально в вашем браузере и никуда не отправляются.

Установка

Chrome / Edge / Brave / Opera

  1. Скачайте архив Chrome с кнопки выше.
  2. Распакуйте его в любую папку.
  3. Откройте chrome://extensions и включите «Режим разработчика».
  4. Нажмите «Загрузить распакованное расширение» и выберите папку.

Firefox 140+

Инструкция ниже подстраивается под файл, на который ведёт кнопка скачивания.

Подписанная версия (.xpi)

  1. Скачайте файл .xpi с кнопки выше.
  2. Откройте скачанный файл — Firefox предложит добавить дополнение.
  3. Нажмите «Добавить» и подтвердите установку.

Подписанная версия обновляется автоматически.

Неподписанная версия (-unsign.xpi)

  1. Скачайте файл .xpi с кнопки выше.
  2. Откройте about:debugging#/runtime/this-firefox.
  3. Нажмите «Загрузить временное дополнение…» и выберите скачанный .xpi.
  4. Дополнение действует только в текущем сеансе — после перезапуска Firefox загрузите его снова.

Неподписанная версия не обновляется автоматически.

Яндекс Браузер

Яндекс Браузер не переопределяет страницу новой вкладки, поэтому расширение запускается кликом по иконке из панели расширений.

  1. Скачайте архив Yandex с кнопки выше.
  2. Распакуйте его в любую папку.
  3. Откройте browser://extensions и включите «Режим разработчика» (внизу страницы).
  4. Нажмите «Загрузить расширение» и выберите распакованную папку.
  5. Закрепите иконку Tabula в панели расширений (через меню «Показать на панели»), чтобы она всегда была под рукой.
  6. Клик по иконке открывает новую вкладку с таблицей. Настройки — иконка ⚙ в её правом верхнем углу.

Если другое расширение уже переопределяет новую вкладку, отключите его — браузер использует только одно такое расширение одновременно.
